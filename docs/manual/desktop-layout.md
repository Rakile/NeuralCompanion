# Desktop layout and appearance

Use the NeuralCompanion logo/name menu to show or hide the main workspaces.
Hiding a view is a layout choice; it is not the same as disabling its addon or
stopping an active runtime.

## Arrange and recover workspaces

- Right-click a workspace tab and choose **Detach to floating window** to move
  it into its own window. Floating windows provide **Always on top**.
- **Lock panel positions** prevents accidental docking and splitter changes.
  Floating windows can still be moved or closed.
- To recover hidden views or an awkward arrangement, open the logo/name menu
  and choose **Reset layout…**. Review **Reset window layout?**, then confirm
  **Reset layout**. This shows the main tabs, unlocks panel positions, and
  restores the default docking positions and sizes. The current workspace
  stays open.

Avatar Preview also has its own **Float preview** action. That preview window
is separate from detaching the whole workspace; see [Avatars](avatars.md).

## Appearance and help

Open **Runtime → Appearance Themes** for the current appearance controls.
These affect NC's interface, independently of a persona's portrait, avatar
pack, or generated-image style. Start with an existing theme and check the
readability of normal, disabled and selected controls before customizing it.
See [Custom appearance themes](../custom-appearance.md) for the color editor,
Save and apply, Cancel, Reset colors and local preference storage.

Hover a control or its label for help. With an editor focused, **F1** opens its
help, **Page Up / Page Down** scroll a long explanation, and **Escape** closes
it. The [settings-help coverage record](desktop-layout.md) identifies
current gaps; a missing tooltip does not mean the setting is unavailable.

The **Tutorials** workspace provides guided navigation. Visiting a tutorial
step does not initialize providers, download models or grant tool access.
Use [First run](first-run.md) for activation and [Troubleshooting](troubleshooting.md)
for provider/runtime failures. To restart the application deliberately, see
[Desktop restart](desktop-restart.md).
