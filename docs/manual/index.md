# NeuralCompanion user guides

Start with the [README overview](../../README.md) if you want to understand what
NeuralCompanion offers. These guides explain how to set up and use individual
features in the current desktop interface.

## Your first conversation

1. [Install NeuralCompanion](installation.md) — prerequisites, optional runtimes, and launch.
2. [First run](first-run.md) — a silent text test, choosing a provider, and saving a chat.
3. [Main chat and conversation controls](conversation.md) — messages, history, reading, images, and command drafts.
4. [Chat and speech](chat-and-tts.md) — language providers, microphones, voices, and streaming.
5. [Personas](personas.md) — personality, portraits, voice assignment, and reusable overrides.

The in-app **Addons → Tutorials** catalog provides guided steps that navigate to
the relevant controls. Search by feature or begin with **First Run**. Reading a
guide does not require activating that feature; narration is optional.

See [Desktop layout and appearance](desktop-layout.md) for floating windows,
hidden workspaces, layout recovery, themes and keyboard help.

## Groups, stories, and other devices

- [Buddy Chat](../addons/buddy_chat.md) — multiple buddies in main chat.
- [Local Room](../addons/local_room.md) — a separate moderated persona discussion.
- [Discord Voice Bridge](../addons/discord_voice.md) — bots in a Discord voice channel.
- [Multi Persona Roleplay](../addons/roleplay.md) — cast, scenes, narration, and Play.
- [Audio Story Mode](../addons/audio_story_mode.md) — chapters, illustrations, and narrated projects.
- [Main Chat Remote](../addons/main_chat_remote.md) — phone pairing and remote access.
- [Internet remote setup](../addons/main_chat_remote_internet_setup.md) — current NC Relay connection.

Main chat and Local Room cannot run together. Follow the stop/save prompts when
switching between them.
