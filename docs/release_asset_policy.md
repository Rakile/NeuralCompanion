# Bundled components and assets

This distribution includes the application source, required provider/runtime bundles, user documentation, interface artwork and selected example voice/avatar/preview assets. Base models and user-created packages are installed or created separately. The owner-approved Nixie LiquidAI voice adapter is included with the Broid and Nixie starter personas.

See [Third-party components and assets](third_party_and_assets.md) for attribution and usage information. Included third-party components keep their licenses and notices. Bundling an asset does not grant a right to use a person's likeness or voice without permission.

The installer checks the pinned Ditto runtime, PocketTTS wheel and VSeeFace bridge inventories before use. Do not edit bundled binaries or checksums to bypass those checks.

Keep personal API keys, conversations, voice recordings, generated media, model weights and avatar packages private unless you deliberately choose to share them and have the necessary rights.
