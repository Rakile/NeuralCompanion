# Avatar Packs

This is the preferred Neural Companion location for MuseTalk and Ditto avatar packs.

Place or install packs here:

```text
avatar_packs/<pack_id>/
```

`Echo_Ditto` is the included prepared still-image Ditto example, displayed as
**Echo**. Install the Ditto runtime, then select the pack in Ditto's provider
settings to preview it or use it in chat. The prepared image and features are
included; an external source image is not required for playback. To prepare it
again, choose **Replace source** and select an image or video.

Large MuseTalk packs such as Echo and Eon are downloaded separately through the
installer. User-created avatar data is ignored by Git; only the small
`Echo_Ditto` example is included in the repository.
