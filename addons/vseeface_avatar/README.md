# VSeeFace avatar addon

Start with the [complete VSeeFace provider guide](../../docs/addons/vseeface.md)
for setup, the Echo test avatar, required receiver settings, body presets,
persona mood tags and bridge maintenance.

Use the **Speech lip sync** section for one-time bridge setup, status, adoption/update and removal.
Users supply their own VSeeFace c4/c5 installation and explicitly approve loader/DLL installation.
Normal NC startup reads the saved enable/path settings. NC remains the audible speech player.

The complete bridge source and optional self-build instructions are in [bridge_source](bridge_source/README.md).
The verified prebuilt DLL, original pinned loader and third-party notices/source are in `bridge_payload/`.
See [Troubleshooting](../../docs/troubleshooting.md#vseeface-speech-lip-sync) for
additional checks. No prototype launcher is required.
