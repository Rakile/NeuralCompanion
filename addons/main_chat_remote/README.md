# Main Chat Remote

Connect a phone to NeuralCompanion over your local network or the Internet.

See the [setup and feature guide](../../docs/addons/main_chat_remote.md) and [Internet setup](../../docs/addons/main_chat_remote_internet_setup.md).

The desktop bridge, phone backend and optional Internet connection are controlled from the addon. Start with local pairing before configuring an Internet relay. Keep credentials private.
