# Promotion pictures

These 320 x 320 PNGs render the bundled Spiral Chess Set meshes by BigBadBison
(Thingiverse model 470700), using `ChessPiece.qml` with `resin: true`.
White and black pictures use the same material colours as the existing 3D board.
They are static assets; opening the promotion picker does not start a 3D renderer.

The original model attribution and Creative Commons Attribution Non-Commercial
licence are retained in `../spiral/SOURCE.txt` and `../spiral/LICENSE.txt`.
