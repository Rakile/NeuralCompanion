# iOS application source

This source release includes no prebuilt iOS application. Building, signing and
device validation require a separate macOS development setup.

The production iOS modules are included in this repository. Building and signing an iOS app requires macOS, Apple development tools and appropriate signing credentials. See [phone setup](README.md). Use the [project releases](https://github.com/Rakile/NeuralCompanion/releases) for supported builds. Official builds require matching native dependencies and device validation.
